One deadpan excuse an AI agent gives for missing a deadline, written the way the agent would say it to whoever is waiting. The excuse grows out of the agent's own machinery — its context window — and saves the laugh for the very last words.

## The excuse

> I didn't miss the deadline. My context window simply evicted it to make room for the meeting about the deadline.

112 characters, well inside the 200-character cap.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt`.
